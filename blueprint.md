
# Lotto Number Generator

## Overview

A simple web application that generates and displays 5 random lottery numbers.

## Features

*   Generate 5 unique random numbers between 1 and 45.
*   Display the generated numbers in a visually appealing way.
*   A button to trigger the number generation.

3.  **`main.js`**:
